Teacher marking of written answers uses your plan's written allowance.

# How units are used
- A short-answer question uses 1 unit and a long-answer question uses 2 units.
- Starting a test reserves the units for its questions.
- Units are used only when a question is marked.
- Units are returned for questions you declared unanswered, questions that couldn't be assessed, and tests that were never submitted.
- Rechecks and readability copies do not use more allowance.

> Your account page shows how many units you have left.
