If you think a released mark is wrong, you can ask for a recheck within 14 days of the result being released.

# How it works
- Choose the questions and explain why they should be marked again.
- A different teacher, who did not mark your script before, marks the same answer again.
- A recheck does not use more allowance.
- Every released version of your marks stays in your mark history; a recheck never erases the first result.

> A recheck looks at the answer you submitted. To answer a question again with new work, start a new practice test instead.
