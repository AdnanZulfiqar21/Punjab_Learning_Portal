| IMPL-16 | 2026-10-07 | **Questions reuse the editorial workflow as content kind `mcq`.** One workflow serves every academic item kind (`kinds.py`). | IMPL-15 | 2026-10-07 | **Staff studio UI.** `/studio` (queue), `/studio/new` and `/studio/items/{id}` run on the web BFF. | IMPL-14 | 2026-10-07 | **Editorial workflow engine (P06).** A `content_item` is a stable identity tied to a chapter (optionally a topic). Its text lives in numbered `content_version`s. Every transition is audited in the same transaction. Source documents carry `publication_rights` (UNVERIFIED/CONFIRMED/DENIED). Only `owner_admin` sets it, with MFA and an evidence reference, and imports never overwrite it. All ten sources are UNVERIFIED, so nothing derived can be published until the owner decides. Drafting and review proceed. *Evidence:* `apps/api/tests/test_content_workflow.py` (11 tests).
