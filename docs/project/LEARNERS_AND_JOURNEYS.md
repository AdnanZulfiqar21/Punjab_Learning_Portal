# LEARNERS AND JOURNEYS (P00.S1.T3)

Roadmap task **P00.S1.T3, "Define initial learners and journeys"** (roadmap §8, P00.S1). Written 2026-10-21. The task asks for the learner types (Class 11, Class 12, repeat entry-test candidate, ICS-to-ECAT candidate, and the purchaser where different from the learner) and for a map of the first-visit, first-lesson, first-practice, paid-access, recovery and support journeys. This file is a record. It describes learners only as far as the roadmap and the records do, and it approves nothing. Every spec named below was checked to exist in `apps/web/e2e/` on 2026-10-21. Those specs run on technical fixtures, not reviewed academic content (JOURNEYS-01; register "P19.S1.T1 New-to-returning learner journeys": fixture content, real content waits on B01).

## Learner types

The roadmap's market is Punjab HSSC Class XI/XII students on the Pre-Medical, Pre-Engineering and relevant ICS entry-test routes, preparing for PMDC MDCAT and UET ECAT (roadmap header, §3). Onboarding asks for grade, Punjab board, stream, target exam and year, explanation language and daily study time (P04.S3.T1; register "P04.S3.T1 Learning preferences" IMPLEMENTED). ## Gaps in one place

- **Purchase:** no checkout, restore or refund journey (B06, B07; D02–D04), and no purchaser journey at all.
- **Mocks:** no MDCAT or ECAT mock journey (B02; SCOPE-01).
- **Account recovery:** no password-reset journey (B04).
- **Video:** no playback assertion (B05).
- **Study plan and evidence pages:** API tests only.
- **Shared-device trial exception:** protocol tests only.
- **Native apps:** `apps/web/e2e` is web only. Android and iOS journeys need installable builds and named devices (B07, B09, B14) and are tracked under the P13 register rows.
- **Real content:** every journey above runs on technical fixtures. AC01 and P19.S1.T1 on real content wait for reviewed material (B01).
- **Phone width:** many learner journeys run on desktop only unless `E2E_FULL_MATRIX` is set (SKIPS-01, `E2E_SKIPS.md`).
- **Learner types:** repeat candidates, ICS-to-ECAT candidates and purchasers have no journey of their own. The roadmap only names them, and the purchaser model is an open owner question.
